# Стан версії 0.3.0

Учень редагує академічний профіль, веде серверні чернетки й подає індивідуальні та командні результати вибраним підтвердженим групам. Диплом можна додати після подання. Windows-клієнт показує надані результати, профілі й документи. Довідники та зв’язування командних записів доступні в Django Admin за дозволами. [Модель даних і матриця доступу](ARCHITECTURE.md#дані-й-права-доступу-в-030)

Збережено Django-сесії та CSRF, ролі, запрошення, групи, спільний клієнт API і стиль 0.2.0. Для нових маршрутів Windows-транспорт підтримує UUID і приватний бінарний потік. Ліміт HTTP-запиту збільшено для одного файла з обмеженням розміру JSON окремо.

## Перевірки

- PostgreSQL 18.6 через TLS — 24/24 тести. SQLite — 22 пройшли, 2 пропущено, оскільки вони перевіряють блокування рядків PostgreSQL. Перевірено вибірковий доступ двох учителів, завершення членства, підміну службових полів, прострочену ревізію, подання без диплома, повтори запитів, командний зв’язок і відкат невдалої заміни. Міграційний тест відтворює схему 0.2.0 з акаунтами й групою та повторює наповнення довідника.
- У Chrome на 320, 390 і 768 px перевірено профіль, майстер і перегляд перед поданням. У перевірених формах axe не виявив порушень правил WCAG A/AA з увімкненого набору. Синтетичний результат подано при закритій Windows-програмі. Чернетка й файл пережили окремі перезапуски Waitress з тією самою PostgreSQL.
- У WebView2 перевірено профіль, фільтр документів, завантаження PDF з тотожними байтами, припинення доступу після вилучення учня та вихід. Зібрано Windows x64 NSIS для тестової адреси `http://127.0.0.1:18003`.
- `check --deploy` завершився без помилок, із попередженнями про HSTS для піддоменів і preload. Ці параметри залежать від конфігурації домену.
- Публічний Docker-деплой та повторний деплой Render/Neon перевіряються після публікації коміту. Чисте встановлення Windows без WebView2 і оновлення поверх 0.2.0 потребують окремої ручної перевірки.

## Ручна перевірка

Відведіть 5–10 хвилин після запуску сервера та підготовки синтетичного учня з підтвердженим членством. Для локальної збірки дотримуйтеся [README](../README.md), для онлайн-збірки використайте адреси з [інструкції пілоту](PILOT.md).

1. Закрийте програму вчителя. На сайті ввійдіть як учень, відкрийте «Мій профіль», заповніть заклад, клас та один інтерес і збережіть.
2. У «Моїх досягненнях» додайте результат МАН із сезоном, секцією й темою. Оберіть «Додам пізніше», звірте групу та збережіть чернетку. Перезавантажте сторінку й відкрийте чернетку зі списку.
3. У програмі вчителя відкрийте профіль учасника та перевірте, що чернетки в «Досягненнях» немає. Закрийте програму. На сайті подайте запис вибраній групі без файла.
4. Відкрийте Windows-клієнт. Перевірте, що результат має позначки «Не перевірено» та «Документ очікується». На сайті натисніть «Додати підтвердження» і збережіть синтетичний PDF. У Windows оновіть список, застосуйте фільтр «Є файл» і завантажте документ.
5. Перезапустіть сервер або повторно розгорніть той самий коміт. Звірте, що доступні той самий результат і файл. Для додаткової перевірки вилучіть синтетичного учня з групи. Після оновлення вчитель втрачає доступ, а учень і далі бачить запис.

## Перед реальними даними

Налаштуйте HTTPS, TLS до PostgreSQL, доступ до бази й адмінки та резервні копії з перевіркою відновлення. Документи зберігаються в окремій таблиці PostgreSQL і витрачають її квоту. Для тестів використовуйте синтетичні профілі та файли. [Ліміти, резервування та видалення](DEPLOYMENT.md#приватні-вкладення-й-резервування)
