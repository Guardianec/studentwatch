# Дизайн Поступу 0.4.1

Кабінет учителя використовує бічну панель із фактурою палітурки й кремове тло із зерном паперу. Академічний огляд показує вибраний рік та групу, підсумки, останні досягнення й окрему колонку справ і напрямів. Центр кабінету учня — особиста головна з останніми результатами, зворотним зв’язком і входом у єдине портфоліо. Ромбовий візерунок із поступовим затіненням під текстом позначає вступ до портфоліо. Поля, кнопки та мобільна навігація мають суцільне тло.

| Роль | Значення |
| --- | --- |
| Полотно | `#fbf3e6` |
| Чорнило | `#2d201b` |
| Другорядний текст | `#654c3f` |
| Дія | `#a63f1c` |
| Навігація вчителя | `#43271e` |
| Додаткова поверхня | `#f4e5d1` |
| Межа | `#e3cbb5` |
| Помилка | `#84262a` |

Інтерфейс використовує системну Segoe UI, зокрема Segoe UI Variable у Windows, а заголовки й ключові результати використовують Georgia. Обидві гарнітури підтримують український текст у Windows. В іншому середовищі діють системні запасні гарнітури. Знак Поступу використовує спільну палітру, а піктограми Lucide доповнюють текстові назви.

Фільтри рівня сторінки використовують адреси. Складніші умови відкриває розкриття. Структуровані ряди переносять груповий стан під назву на вузькому екрані. Основні екрани — окремі маршрути. Діалоги використовуються для редагування групи й підтвердження важливих дій. Участь, бали, докази та додатковий опис відкриваються у формі за потреби.

До 760 px навігація вчителя переходить у меню. До 660 px учнівська навігація закріплена внизу з підписами та запасом для системної зони. Довгі назви переносяться. Інтерфейс підтримує клавіатуру, видимий фокус, перехід до основного вмісту, текстові стани та оголошення результатів дій. Анімація переходу на 170 мс використовує малий зсув і майже повну непрозорість, а відгук кнопок не змінює макета. За `prefers-reduced-motion: reduce` ці ефекти вимкнені.

Джерела й відхилені варіанти задокументовано в [дослідженні дизайну](design-research-0.4.1.md).
