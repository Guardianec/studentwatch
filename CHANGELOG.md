# Журнал змін

## 0.3.0

- Додано академічний профіль учня з окремими блоками навчання, інтересів і посилань. Профіль доступний учителям за чинного підтвердженого членства. Відомості учасників у Windows більше не містять логінів.
- Додано довідники категорій, конкурсів, циклів і етапів та форму результату з трьох кроків. Вона підтримує серверні чернетки, попередження про схожі записи, вибір груп, подання й відкликання.
- Командні записи можуть посилатися на спільний результат після підтвердження зв’язку уповноваженим адміністратором.
- Додано необов’язкові PDF, JPEG і PNG з перевіркою вмісту, приватним доступом і можливістю пізніше додати, замінити або вилучити матеріал.
- Windows-клієнт показує надані результати, профілі, фільтри й приватні завантаження. Міграція зберігає наявні акаунти, групи та членства.

## 0.2.0

- Додано учнівську реєстрацію, вхід, вихід, редагування ПІБ та відновлення сесії. Учительську роль призначає адміністратор Django.
- Кабінет Windows показує групи, заявки й учасників із сервера. Учитель може створити, редагувати та архівувати групу, керувати запрошенням і вирішувати заявки.
- Додано початкову міграцію, обмеження спроб, транзакційне членство та production-конфігурацію PostgreSQL.
- Windows зберігає ключ сесії в Credential Manager, учнівський сайт використовує HttpOnly cookie й CSRF-захист Django.
- Підготовлено розгортання сайту й API на Render з PostgreSQL у Neon та перевірками в GitHub Actions. Вподобайка вчителя зберігається за номером версії.

## 0.1.0

- Додано українську оболонку «Поступу» для Windows і браузерного перегляду.
- Додано демонстраційний огляд, списки учнів і досягнень та чергу. На широкому екрані відомості про вибрану заявку відкриваються поряд зі списком.
- Оформлено кабінет у теплій палітрі друкованого журналу й виокремлено результат учня у відомостях про заявку.
- Додано каркас Django з перевіркою доступності сервера й окремими станами підключення.
- Зібрано інсталятор Windows x64, перевірено тестове встановлення та запуск із ярлика.
- Описано вимоги, логічну схему даних і критерії наступних версій.
